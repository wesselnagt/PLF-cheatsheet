PLF08: Routing, NAT & RRAS

Het configureren van netwerkinterfaces en Windows Server als softwarematige router.

1. Netwerkkaarten Configureren in Windows

Zorg dat de juiste interfaces gekoppeld zijn. Gebruik PowerShell om IP-adressen statisch in te stellen op de router-VM:

powershellNew-NetIPAddress -InterfaceAlias "VMNET2" -IPAddress 172.19.19.1 -PrefixLength 24
New-NetIPAddress -InterfaceAlias "Internal" -IPAddress 192.168.1.10 -PrefixLength 24
De internet-interface (VMnet8) moet op DHCP blijven staan om automatisch een IP en gateway van VMware te ontvangen.

2. RRAS & NAT Installatie

Installeer de Remote Access-rol inclusief Routing functionaliteit:

powershellInstall-WindowsFeature -Name RemoteAccess, Routing -IncludeManagementTools

Configuratie stappen in GUI (rrasmgmt.msc):

  1. Rechtermuisknop op servernaam -> Configure and Enable Routing and Remote Access.
  2. Kies Network Address Translation (NAT).
  3. Selecteer de interface die met het internet is verbonden (VMnet8 NAT) en voltooi de wizard.

3. Troubleshooting: Metric Aanpassen

Vechtende gateways? Als internet op de router niet werkt, dwing de internetinterface (VMnet8) dan af als hoofdroute door de metric te verlagen.
powershellSet-NetIPInterface -InterfaceAlias "VMNET8" -InterfaceMetric 5
Set-NetIPInterface -InterfaceAlias "Ethernet0" -InterfaceMetric 80

PLF09: Active Directory Sites & Replication

Het indelen van fysieke locaties binnen Active Directory en het configureren van replicatieschema's.

1. Extra Domain Controller Promoveren

Voer dit uit op de Core-server om AD-DS te installeren en te promoveren tot extra Domain Controller binnen het bestaande domein:

powershellInstall-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools
Install-ADDSDomainController -DomainName "school.test" -Credential (Get-Credential)

2. Sites en Subnets Inrichten (GUI)

Open Active Directory Sites and Services (dssite.msc) op de hoofd DC:

  1. Klik met de rechtermuisknop op Sites -> New Site. Maak de gevraagde locaties aan (bijv. Leeuwarden en Groningen).
  2. Ga naar Subnets -> New Subnet. Voeg de IP-ranges toe en koppel ze aan de juiste site (bijv. 192.168.1.0/24 aan Leeuwarden).
  3. Sleep de servers vanuit Default-First-Site-Name naar hun respectievelijke nieuwe site.

3. Replicatie Schema Aanpassen & Controleren

Ga naar Inter-Site Transports -> IP, open de eigenschappen van de sitelink en klik op Change Schedule. Selecteer de blokken waarin wel/niet gerepliceerd mag worden.

Forceren en status opvragen via CMD:

cmdrepadmin /syncall /AePdq
repadmin /showrepl

PLF10: Windows Group Policies (GPO)

Centraal beleid afdwingen voor gebruikers en computers binnen de Active Directory.

1. GPO Aanmaken en Koppelen

Open gpmc.msc (Group Policy Management). Maak een nieuwe GPO aan onder Group Policy Objects. Koppel deze vervolgens aan een specifieke OU of aan de domein-root.

Let op: Wachtwoord- en accountpolicies werken alléén als ze gekoppeld zijn aan de ROOT van het domein!

2. Veelgestelde Beleidsregels (GPO Settings)

Functie GPO Pad Instelling
Wachtwoordlengte / Historie Computer Conf -> Policies -> Windows Settings -> Security Settings -> Account Policies -> Password Policy Min. password length / History
Cmd / Run blokkeren User Conf -> Policies -> Administrative Templates -> System Prevent access to the command prompt
Uitvoeren (Run) verbergen User Conf -> Policies -> Administrative Templates -> Start Menu and Taskbar Remove Run menu from Start Menu

3. Handhaven (Enforce) & Rapporteren

Om te zorgen dat er niet van de policy afgeweken mag worden: klik met de rechtermuisknop op de koppeling van de GPO en vink Enforced aan.

Genereer het verplichte HTML-toetsrapport via PowerShell:

powershellGet-GPO -Name "wachtwoord" | Get-GPOReport -ReportType HTML -Path C:\wachtwoord_rapport.html

PLF11: Windows Systeembeveiliging & PKI

Lokaal beveiligingsbeleid, auditing en certificaatbeheer (Public Key Infrastructure).

1. Auditing (Gebeurtenisbewaking) Inrichten

Om te loggen wanneer gebruikers inloggen of bestanden openen, navigeer in een GPO naar:

Computer Configuration -> Policies -> Windows Settings -> Security Settings -> Local Policies -> Audit Policy

Zet bijvoorbeeld Audit logon events op Success en Failure om inlogpogingen bij te houden in de Event Viewer.

2. Active Directory Certificate Services (AD-CS)

Heeft de toets een certificaatautoriteit nodig? Installeer de CA-rol:

powershellInstall-WindowsFeature -Name ADCS-Cert-Authority -IncludeManagementTools

Configureer de CA via de vlag-notificatie in Server Manager als Enterprise CA zodat domeincomputers automatisch certificaten kunnen vertrouwen.

PLF12: OpenVPN op Rocky Linux

Het installeren, configureren en beveiligen van een Linux-gebaseerde VPN-tunnel.

1. Repositories Herstellen & Pakketten Installeren

Voer dit uit op beide Rocky Linux VM's om de pakketbronnen te herstellen en OpenVPN binnen te halen:

bashsudo rm -f /etc/yum.repos.d/Rocky-*
sudo dnf reinstall rocky-repos -y
sudo dnf install epel-release -y
sudo dnf install openvpn easy-rsa -y

2. Public Key Infrastructure (PKI) Bouwen op Server

Initialiseer de certificaatmap en bouw de Certificate Authority op:

bashmake-cadir ~/openvpn-ca
cd ~/openvpn-ca
nano vars  # Pas indien gevraagd land, stad, organisatie en e-mail aan
./easyrsa init-pki
./easyrsa build-ca nopass
./easyrsa gen-req server nopass
./easyrsa sign-req server server
./easyrsa gen-dh
openvpn --genkey secret ta.key

3. Routing & Client Verbinding

Zorg dat de server de interne route pushed naar de client via het server configuratiebestand (/etc/openvpn/server/server.conf):

textpush "route 192.168.1.0 255.255.255.0"

Start de VPN-server op Linux:

bashsudo systemctl enable --now openvpn-server@server

Praktijktoets Gids: Voorbeeldtoets E

Focus: Windows RRAS Routing, NAT en Active Directory Group Policies.

Geen screenshots verplicht! De beoordelaar komt live langs om de werking te controleren op je scherm.

Stap 1: Netwerkinrichting (VMware & Windows)

  1. Hernoem de servers: de GUI-router naar RRAS1 en de Core-server naar Core1 (via sconfig).
  2. Zorg voor de juiste netwerkkaarten op RRAS1:
    • Adapter 1: Interne netwerk (VMnet0 / richting DC1 op 192.168.1.1).
    • Adapter 2: Custom (VMnet2 / richting Core1).
    • Adapter 3: Custom (VMnet8 (NAT) / richting internet).
  3. Stel op Core1 het IP in op 172.19.19.2 met Default Gateway 172.19.19.1.
  4. Zet ping-respons aan op Core1 met sconfig (Optie 4 -> Optie 3 -> Enable).

Stap 2: RRAS NAT Configureren

  1. Installeer de Remote Access rol met de Routing service op RRAS1.
  2. Open rrasmgmt.msc, activeer de service en voeg onder IPv4 -> NAT de interfaces toe:
    • VMNET8: Public interface + vinkje bij Enable NAT aan.
    • VMnet2: Private interface.
  3. Mochten pings naar buiten vanaf RRAS1 falen, pas de interface metrics aan in PowerShell (zie PLF08 tabblad).

Stap 3: Groepsbeleid (GPO) Configureren

  1. Maak op DC1 een gebruiker aan genaamd bob.
  2. Maak een GPO genaamd norun. Ga naar User Configuration -> Templates -> System en zet Prevent access to the command prompt op Enabled. Koppel deze aan de OU van Bob.
  3. Maak een GPO genaamd wachtwoord. Koppel deze aan de root van het domein. Stel de eisen in: Historie = 3, Max leeftijd = 20, Min lengte = 10.
  4. Klik met de rechtermuisknop op beide GPO-koppelingen en kies Enforced.
  5. Genereer het HTML-rapport via PowerShell: 
    powershellGet-GPO -Name "wachtwoord" | Get-GPOReport -ReportType HTML -Path c:\report.html

Praktijktoets Gids: Voorbeeldtoets F

Focus: Linux OpenVPN-tunneling en Active Directory Replication & Sites.

Stap 1: Linux Netwerk & Repo Herstel

  1. Koppel rocky1 aan de interne AD-switch en geef deze een extra kaart in VMnet8 (NAT). Koppel rocky2 enkel aan VMnet8 (NAT).
  2. Herstel op beide Linux-machines direct de pakketbronnen: 
    bashsudo rm -f /etc/yum.repos.d/Rocky-* && sudo dnf reinstall rocky-repos -y
  3. Installeer `openvpn` en `easy-rsa` op beide systemen.

Stap 2: VPN Opbouwen

  1. Genereer de certificaten op `rocky1` via `easyrsa`. Zorg dat de land- en organisatiegegevens in de `vars`-file exact overeenkomen met de toetscriteria.
  2. Zet in de serverconfiguratie de push-route aan richting het interne LAN: `push "route 192.168.1.0 255.255.255.0"`.
  3. Breng de certificaten over naar `rocky2`, pas het clientconfiguratiebestand aan met het NAT-IP van `rocky1` en start de verbinding.
  4. Succescriterium: Vanaf `rocky2` kun je succesvol pingen naar je Windows Domain Controller op `192.168.1.1`.

Stap 3: AD Sites & Replicatieschema

  1. Promoveer `Core1` tot extra Domain Controller binnen het domein.
  2. Open Active Directory Sites and Services op de hoofd-DC.
  3. Maak de sites `Leeuwarden` en `Groningen` aan. Sleep DC1 naar Leeuwarden en Core1 naar Groningen.
  4. Maak de bijbehorende subnets aan en koppel ze aan de juiste site.
  5. Pas de IP-sitelink aan: zet het schema op maandag t/m vrijdag tussen 09:00 en 18:00 op **twee keer per uur** (30 min interval). Kleur alle andere uren wit (niet repliceren).
  6. Forceer de eerste replicatie via CMD: `repadmin /syncall /AePdq`.
