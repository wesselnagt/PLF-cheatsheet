PLF08: Windows Routing & NAT

Windows Server transformeren tot een softwarematige router met NAT-functionaliteit.

Stap 1: Netwerkkaarten en IP-adressen inrichten

SERVER: RRAS1 (GUI)
  1. Zorg in VMware dat deze VM 3 netwerkkaarten heeft: VMnet0 (naar DC), VMnet2 (naar Core) en VMnet8 (NAT/Internet).
  2. Open PowerShell en stel de statische IP-adressen in:
    3. powershell# Interface naar Core1 instellen:
New-NetIPAddress -InterfaceAlias "Ethernet 1" -IPAddress 172.19.19.1 -PrefixLength 24

# Interface naar de Domain Controller (DC1) instellen:
New-NetIPAddress -InterfaceAlias "Ethernet 0" -IPAddress 192.168.1.10 -PrefixLength 24

Stap 2: RRAS Rol en Routering Installeren

SERVER: RRAS1 (GUI)
  1. Open Server Manager. Klik rechtsboven op Manage > Add Roles and Features.
  2. Klik 3x op Next. Vink bij 'Server Roles' de optie Remote Access aan.
  3. Klik 3x op Next. Vink bij 'Role Services' de opties DirectAccess and VPN (RAS) én Routing aan. Klik Install.
  4. Druk na de installatie op de Windows-toets, typ rrasmgmt.msc en druk op Enter.
  5. Klik met de rechtermuisknop op de naam van je server en kies Configure and Enable Routing and Remote Access.
  6. Klik Next, selecteer Network address translation (NAT) en klik Next.
  7. Kies de netwerkkaart die met het internet is verbonden (Degene met DHCP/VMnet8) en klik Finish.

Stap 3: Metric Fix voor Internettoegang

SERVER: RRAS1 (GUI)
  1. Als je vanaf de Core server niet naar buiten kunt pingen, vechten je gateways met elkaar. Los dit op in PowerShell:
    2. powershell# Dwing internetkaart (VMnet8) naar de hoogste prioriteit
Set-NetIPInterface -InterfaceAlias "VMnet8" -InterfaceMetric 5

# Zet de interne kaarten op een hele lage prioriteit
Set-NetIPInterface -InterfaceAlias "Ethernet 0" -InterfaceMetric 80
Set-NetIPInterface -InterfaceAlias "Ethernet 1" -InterfaceMetric 80

PLF09: Active Directory Sites & Replicatie

AD fysiek opdelen in locaties (Sites) en replicatieschema's afdwingen.

Stap 1: Core Server Promoveren tot extra DC

SERVER: CORE1
  1. Zorg dat Core1 via sconfig het juiste IP heeft én dat DNS verwijst naar DC1 (192.168.1.1).
  2. Typ powershell in het zwarte CMD-scherm en voer dit uit:
    3. powershell# Active Directory rollen installeren
Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools

# Promoveren tot extra Domain Controller in het domein
Install-ADDSDomainController -DomainName "school.test" -Credential (Get-Credential)
  3. Vul bij de pop-up de gegevens in van de domein-admin (bijv. SCHOOL\Administrator) en laat de server herstarten.

Stap 2: Sites en Subnets Aanmaken in GUI

SERVER: DC1
  1. Druk op de Windows-toets, typ dssite.msc en druk op Enter.
  2. Klik met de rechtermuisknop op de map Sites en kies New Site...
  3. Typ Leeuwarden, klik op DEFAULTIPSITELINK en klik OK. Doe dit direct nog een keer voor Groningen.
  4. Klik met de rechtermuisknop op de map Subnets en kies New Subnet...
  5. Typ bij Prefix 192.168.1.0/24, klik eronder op Leeuwarden en klik OK.
  6. Typ bij Prefix 172.19.19.0/24, klik eronder op Groningen en klik OK.
  7. Vouw open: Sites > Default-First-Site-Name > Servers.
  8. Sleep je hoofd-DC met je muis naar de map Leeuwarden en sleep Core1 naar de map Groningen.

Stap 3: Replicatieschema Inrichten & Forceren

SERVER: DC1
  1. Vouw links open: Inter-Site Transports > IP.
  2. Klik met de rechtermuisknop op DEFAULTIPSITELINK en kies Properties.
  3. Verander Replicate every naar het gevraagde aantal minuten (bijv. 30).
  4. Klik op Change Schedule...
  5. Zet het hele blok op wit (Replication Not Available) en markeer uitsluitend de gewenste werktijden blauw (Replication Available). Klik OK.
  6. Open Command Prompt en forceer de synchronisatie:
    7. cmdrepadmin /syncall /AePdq
repadmin /showrepl

PLF10: Group Policies (GPO) Configureren

Het afdwingen van restricties en wachtwoordbeleid in Active Directory.

Stap 1: Wachtwoordbeleid (Op ROOT niveau!)

SERVER: DC1
Let op: Een Password Policy werkt alléén als je hem koppelt aan de ROOT van het domein, niet aan een OU.
  1. Druk op de Windows-toets, typ gpmc.msc en druk op Enter.
  2. Vouw open tot je Group Policy Objects ziet. Rechtermuisknop > New > Typ wachtwoord > OK.
  3. Rechtermuisknop op wachtwoord > Edit.
  4. Navigeer naar: Computer Configuration > Policies > Windows Settings > Security Settings > Account Policies > Password Policy.
  5. Stel in: Enforce password history (bijv. 3), Maximum password age (bijv. 20) en Minimum password length (bijv. 10). Sluit af.
  6. Klik met de rechtermuisknop helemaal bovenaan op je domein (school.test) > Link an Existing GPO... > Kies wachtwoord.
  7. Rechtermuisknop op de nieuwe koppeling > Klik op Enforced.

Stap 2: Command Prompt / Run Blokkeren (Op OU niveau)

SERVER: DC1
  1. Zorg dat je via dsa.msc een OU hebt gemaakt met daarin een gebruiker (bijv. Bob).
  2. Ga terug naar gpmc.msc. Maak in Group Policy Objects een nieuwe GPO genaamd norun.
  3. Rechtermuisknop op norun > Edit.
  4. Navigeer naar: User Configuration > Policies > Administrative Templates > System.
  5. Dubbelklik op Prevent access to the command prompt > Zet op Enabled > OK. Sluit af.
  6. Klik in GPMC met de rechtermuisknop op de OU van je gebruiker > Link an Existing GPO... > Kies norun.
  7. Rechtermuisknop op de koppeling > Klik op Enforced.

Stap 3: Verplicht HTML-Rapport Genereren

SERVER: DC1
  1. Open PowerShell en voer dit uit om het GPO-rapport voor de beoordelaar te maken:
    2. powershellGet-GPO -Name "wachtwoord" | Get-GPOReport -ReportType HTML -Path C:\report.html

PLF11: Systeembeveiliging & AD-CS

Beveiligingslogs aanzetten en een Enterprise Certificate Authority (CA) bouwen.

Stap 1: Auditing (Logboek) Inschakelen via GPO

SERVER: DC1
  1. Open gpmc.msc. Klik met de rechtermuisknop op de Default Domain Policy > Edit.
  2. Navigeer naar: Computer Configuration > Policies > Windows Settings > Security Settings > Local Policies > Audit Policy.
  3. Dubbelklik op Audit logon events en vink zowel Success als Failure aan.
  4. Dubbelklik op Audit account management en vink Success en Failure aan. Klik OK en sluit af.

Stap 2: Enterprise Certificate Authority Installeren

SERVER: DC1
  1. Open Server Manager. Klik rechtsboven op Manage > Add Roles and Features.
  2. Klik Next tot je bij Server Roles bent. Vink Active Directory Certificate Services aan (Add features). Klik door en Install.
  3. Klik na installatie op de gele waarschuwingsvlag (Configure Active Directory Certificate Services) bovenin.
  4. Klik op Next. Vink Certification Authority aan en klik Next.
  5. Selecteer Enterprise CA en klik Next.
  6. Selecteer Root CA en klik Next.
  7. Selecteer Create a new private key en klik Next.
  8. Selecteer in de lijst SHA256 en klik Next.
  9. Klik op Next tot het einde en klik op Configure. Je domein kan nu lokaal vertrouwde certificaten uitdelen.

PLF12: OpenVPN op Linux

Een werkende VPN-tunnel opzetten tussen twee Rocky Linux machines.

Stap 1: Repositories & Installatie (Op BEIDE servers)

SERVER: ROCKY1 & ROCKY2
  1. Voer dit uit op zowel Server als Client om errors te voorkomen en software te installeren:
    2. bashsudo rm -f /etc/yum.repos.d/Rocky-*
sudo dnf reinstall rocky-repos -y
sudo dnf install epel-release -y
sudo dnf install openvpn easy-rsa -y

Stap 2: Certificaten Genereren (Op VPN Server)

SERVER: ROCKY1
  1. Bouw de CA (Certificate Authority):
    2. bashmake-cadir ~/openvpn-ca
cd ~/openvpn-ca
./easyrsa init-pki
./easyrsa build-ca nopass
  2. Genereer alle benodigde sleutels voor server én client:
    3. bash./easyrsa gen-req server nopass
./easyrsa sign-req server server
./easyrsa gen-dh
openvpn --genkey secret ta.key
./easyrsa gen-req client1 nopass
./easyrsa sign-req client client1
  3. Kopieer de serverbestanden naar de juiste directory:
    4. bashsudo cp pki/ca.crt pki/issued/server.crt pki/private/server.key dh.pem ta.key /etc/openvpn/server/

Stap 3: Server Configuratie Maken

SERVER: ROCKY1
  1. Maak het bestand aan: sudo nano /etc/openvpn/server/server.conf
  2. Plak dit in de editor (zorg dat de "push route" klopt met je interne Windows netwerk!):
    3. textport 1194
proto udp
dev tun
ca ca.crt
cert server.crt
key server.key
dh dh.pem
server 10.8.0.0 255.255.255.0
push "route 192.168.1.0 255.255.255.0"
keepalive 10 120
tls-auth ta.key 0
cipher AES-256-GCM
user nobody
group nobody
persist-key
persist-tun
status openvpn-status.log
verbosity 3
  3. Sla op (Ctrl+O > Enter > Ctrl+X) en start de server: sudo systemctl enable --now openvpn-server@server

Stap 4: Client Configureren

SERVER: ROCKY2
  1. Kopieer de bestanden ca.crt, client1.crt, client1.key en ta.key vanuit rocky1 naar de map /etc/openvpn/client/ op rocky2 (via SCP of gedeelde mappen).
  2. Maak het client-bestand aan: sudo nano /etc/openvpn/client/client.conf
  3. Voeg de standaard client config in, waarbij je de regel remote IP-ADRES 1194 aanpast naar het NAT-IP van Rocky1. Sla op en start:
    4. bashsudo systemctl enable --now openvpn-client@client

Overlevingsgids: Voorbeeldtoets E

Focus: Routing (NAT) opzetten en Group Policies beveiligen.

Zorg dat al je 3 virtuele machines aan staan: DC1, je GUI-server (wordt RRAS1) en je Core-server (wordt Core1).

Deel 1: Netwerkkaarten in VMware instellen

  1. Klik in VMware bovenin op de tab van je GUI-server (RRAS1).
  2. Klik op VM > Settings.
  3. Zorg dat je in totaal DRIE (3) Network Adapters hebt. Klik eventueel op Add... > Network Adapter > Finish als je er tekort komt.
  4. Stel ze exact zo in:
    - Network Adapter 1: Selecteer Custom: VMnet0 (Dit is de koppeling naar DC1).
    - Network Adapter 2: Selecteer Custom: VMnet2 (Dit is de koppeling naar Core1).
    - Network Adapter 3: Selecteer Custom: VMnet8 (NAT) (Dit is het internet).
  5. Klik op OK.
  6. Ga in VMware naar de tab van je Core-server (Core1). Klik op VM > Settings.
  7. Zorg dat deze ÉÉN (1) Network Adapter heeft. Stel deze in op Custom: VMnet2. Klik op OK.

Deel 2: IP-adressen uitdelen en Ping aanzetten

SERVER: CORE1
  1. Log in op Core1. Typ sconfig en druk op Enter.
  2. Typ 2 (Computer Name) > Typ Core1. Hij vraagt om een herstart, klik Yes.
  3. Na herstart, open sconfig. Typ 4 (Remote Management) > Typ 3 (Ping) > Klik Yes. Typ 4 (Return).
  4. Typ 8 (Network Settings). Kies het getal van je netwerkkaart (meestal 1).
  5. Typ 1 (Set IP) > Typ S (Static) > Typ IP 172.19.19.2 > Typ Subnet 255.255.255.0 > Typ Gateway 172.19.19.1.
  6. Typ 2 (Set DNS) > Typ 192.168.1.1.
SERVER: RRAS1 (GUI)
  1. Log in op RRAS1. Open PowerShell.
  2. Voer deze commando's uit om de statische IP-adressen goed te zetten:
    3. powershellNew-NetIPAddress -InterfaceAlias "Ethernet 1" -IPAddress 172.19.19.1 -PrefixLength 24
New-NetIPAddress -InterfaceAlias "Ethernet 0" -IPAddress 192.168.1.10 -PrefixLength 24

Deel 3: Router & NAT Installeren op RRAS1

SERVER: RRAS1 (GUI)
  1. Open Server Manager. Klik op Manage > Add Roles and Features.
  2. Installeer de Server Role: Remote Access.
  3. Vink bij Role Services aan: DirectAccess and VPN (RAS) en Routing. Klik Install.
  4. Druk op de Windows-toets, typ rrasmgmt.msc en druk op Enter.
  5. Rechtermuisknop op de server > Configure and Enable Routing and Remote Access.
  6. Kies Network address translation (NAT) en klik Next.
  7. Selecteer de netwerkkaart die met VMnet8 is verbonden en klik Finish.
  8. FIX GATEWAY METRIC: Open PowerShell en voer dit in:
    9. powershellSet-NetIPInterface -InterfaceAlias "VMnet8" -InterfaceMetric 5
Set-NetIPInterface -InterfaceAlias "Ethernet 0" -InterfaceMetric 80
Set-NetIPInterface -InterfaceAlias "Ethernet 1" -InterfaceMetric 80
TESTMOMENT: Ga naar Core1. Typ ping 8.8.8.8. Werkt dit? Gefeliciteerd!

Deel 4: Group Policies (GPO) configureren op DC1

SERVER: DC1
  1. Open dsa.msc. Maak een OU genaamd ToetsOU en daarin een User genaamd bob (wachtwoord Pa$$w0rd).
  2. Open gpmc.msc. Maak in Group Policy Objects een nieuwe GPO genaamd wachtwoord. Edit deze.
  3. Navigeer naar: Computer Config > Policies > Windows Settings > Security Settings > Account Policies > Password Policy.
  4. Stel in: Enforce history (3), Max age (20), Min length (10).
  5. KOPPEL AAN ROOT: Rechtermuisknop op je domeinnaam (school.test) > Link an Existing GPO... > Kies wachtwoord. Rechtermuisknop op de nieuwe link > Enforced.
  6. Maak GPO norun. Edit deze. Navigeer naar: User Config > Policies > Administrative Templates > System.
  7. Zet Prevent access to the command prompt op Enabled.
  8. Koppel norun aan de OU ToetsOU en zet ook deze op Enforced.
  9. Open PowerShell en maak het rapport:
    10. powershellGet-GPO -Name "wachtwoord" | Get-GPOReport -ReportType HTML -Path C:\report.html
