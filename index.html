⏱️ Start-routine & Tijdmanagement (45 min)

Je hebt 15 minuten per taak. Tijd is je grootste vijand.

  • Minuut 1-3: Lees de 3 taken. Identificeer afhankelijkheden. Moet je een CA opzetten voordat je VPN kunt configureren? Doe dat in de juiste volgorde.
  • Multitasken is verplicht: Start direct de installatie van zware Server Roles (ADDS, AD CS, RRAS). Terwijl de blauwe balkjes lopen, configureer je alvast IP-adressen via ncpa.cpl of schrijf je je Linux configuratie uit.
  • Ping & DNS: 90% van de fouten komt door DNS. Werkt het joinen van een nieuwe VM aan het domein niet? Controleer direct je netwerkadapter: je Primary DNS moet naar je Domain Controller wijzen.

🟢 PLF08: Directory Services 1

Windows RRAS (Router & NAT) via GUI

  1. Role Installeren: Server Manager > Manage > Add Roles and Features > Vink Remote Access aan > Vink bij Role Services Routing aan.
  2. Activeren: Tools > Routing and Remote Access (RRAS).
  3. Rechtsklik op de servernaam > Configure and Enable Routing and Remote Access.
  4. Kies Custom Configuration > Vink NAT én LAN routing aan > Finish > Start de service.
  5. NAT Instellen: Vouw IPv4 uit > Rechtsklik op NAT > New Interface.
  6. Kies de netwerkkaart die naar buiten gaat (WAN) > Selecteer Public interface connected to the Internet > Vink Enable NAT on this interface aan. (Voeg daarna de interne interface toe als Private interface connected to private network).

VyOS Base Routing & NAT (Linux CLI)

Gebruik de CLI. Om tijd te besparen bij het overschakelen tussen machines, kun je vooraf je public-key string instellen voor passwordless SSH, zodat je razendsnel commando's kunt plakken.

configure
# Interfaces instellen
set interfaces ethernet eth0 address dhcp                # Buitenkant (WAN)
set interfaces ethernet eth1 address 192.168.10.1/24     # Binnenkant (LAN)

# NAT (Masquerade) instellen
set nat source rule 100 outbound-interface eth0
set nat source rule 100 source address 192.168.10.0/24
set nat source rule 100 translation address masquerade

# Default route instellen
set protocols static route 0.0.0.0/0 next-hop <IP_VAN_GATEWAY>

commit
save
exit

🔵 PLF09: Directory Services 2

AD Sites & Subnets (GUI)

  1. Tools > Active Directory Sites and Services.
  2. Site aanmaken: Rechtsklik op Sites > New Site > Geef een naam en koppel aan DEFAULTIPSITELINK.
  3. Subnet koppelen: Rechtsklik op Subnets > New Subnet > Typ de prefix in (bijv. 10.0.0.0/24) > Selecteer in de lijst eronder de zojuist gemaakte Site.
  4. DC verplaatsen: Vouw de Default-First-Site-Name uit, sleep de Domain Controller naar de nieuwe Site.

DHCP Failover (GUI)

Voorwaarde: De DHCP-role moet op beide servers (bijv. Primary en T-DHCP-02) geïnstalleerd én geautoriseerd zijn.

  1. Tools > DHCP > Vouw de lokale server uit > IPv4.
  2. Rechtsklik op een bestaande Scope > Configure Failover.
  3. Vink Select all aan > Next.
  4. Voer het IP of de naam in van je partner server (bijv. T-DHCP-02) > Next.
  5. Kies de Mode: Hot Standby (1 actief, 1 reserve) of Load Balance (beide actief delen het werk).
  6. Vink State Switchover Interval aan (bijv. 1 minuut) > Next > Finish.

Storage Pools & Spaces (GUI)

  1. Server Manager > File and Storage Services > Volumes > Storage Pools.
  2. Rechtsklik rechtsboven in de lege ruimte (bij Primordial) > New Storage Pool > Geef een naam > Vink de lege, fysieke schijven aan.
  3. Rechtsklik op de nieuwe pool > New Virtual Disk > Kies Mirror of Parity > Kies Thin of Fixed provisioning.
  4. Doorloop de volume-wizard om een schijfletter en NTFS/ReFS in te stellen.

🟠 PLF10: Group Policies (GPO)

Central Store Aanmaken (GUI)

  1. Open de Verkenner (Win + E).
  2. Kopieer de map: C:\Windows\PolicyDefinitions
  3. Plak deze in de SYSVOL share: \\JOUWDOMEIN.local\SYSVOL\JOUWDOMEIN.local\Policies\

Folder Redirection (GUI)

  1. Maak een map op je fileserver (bijv. C:\Shares\Profiles). Deel deze (Share: Everyone = Full Control. NTFS: Creator Owner = Full Control, Authenticated Users = Read/Write/Execute).
  2. Open gpmc.msc > Maak/Edit een GPO gelinkt aan de OU met Users.
  3. User Configuration > Policies > Windows Settings > Folder Redirection.
  4. Rechtsklik op Documents > Properties.
  5. Setting: Basic > Root Path: \\SERVERNAAM\Profiles.

Loopback Processing (Kiosk Mode)

  1. Link de GPO aan de OU waar de Computers in zitten.
  2. Edit GPO: Computer Configuration > Policies > Administrative Templates > System > Group Policy.
  3. Zet Configure user Group Policy loopback processing mode op Enabled.
  4. Kies Replace of Merge.

🔴 PLF11: Windows Beveiliging & PKI

Enterprise CA (Certificate Authority)

  1. Installatie: Server Manager > Add Roles > Active Directory Certificate Services.
  2. Configuratie: Kies Enterprise CA > Root CA > Create a new private key.
  3. Template dupliceren: Tools > Certification Authority. Rechtsklik Certificate Templates > Manage.
  4. Rechtsklik op User (of Computer) > Duplicate Template. Geef het een naam.
  5. Tabblad Security: Voeg Domain Users/Computers toe. Vink aan: Read, Enroll, én Autoenroll.
  6. In de CA-console: Rechtsklik Certificate Templates > New > Certificate Template to Issue > Selecteer je nieuwe template.

Auto-enrollment via GPO

  1. Edit een GPO. User Configuration > Policies > Windows Settings > Security Settings > Public Key Policies.
  2. Open Certificate Services Client - Auto-Enrollment.
  3. Zet op Enabled en vink de twee onderste vakjes aan.

IPsec via Windows Firewall (GUI)

  1. GPO > Computer Configuration > Policies > Windows Settings > Security Settings > Windows Defender Firewall.
  2. Rechtsklik op Connection Security Rules > New Rule.
  3. Kies Isolation > Require authentication for inbound and outbound > Kies Computer and User (Kerberos V5).

🟣 PLF12: VPN & Beveiliging

RRAS VPN (SSTP & L2TP) (GUI)

  1. SSTP Certificaat: Vraag een "Computer" certificaat aan op je VPN-server via certlm.msc.
  2. IIS Binding: Open IIS Manager > Default Web Site > Bindings > Voeg HTTPS (poort 443) toe > Selecteer het certificaat.
  3. L2TP Preshared Key: In RRAS > Rechtsklik server > Properties > Tabblad Security > Vink Allow custom IPsec policy for L2TP/IKEv2 aan en voer de sleutel in.

NPS (Network Policy Server) Instellen

  1. Tools > Network Policy Server (nps.msc).
  2. Policies > Network Policies > Rechtsklik > New.
  3. Naam: "VPN Toegang".
  4. Conditions: Voeg je Active Directory VPN-groep toe.
  5. Access Permission: Access granted.
  6. Authentication Methods: Vink MS-CHAP-v2 aan. Zorg dat deze policy bovenaan staat!

WireGuard (Linux CLI)

# Genereer keys
wg genkey | tee privatekey | wg pubkey > publickey

# Maak de interface aan (nano /etc/wireguard/wg0.conf)
[Interface]
Address = 10.0.0.1/24
ListenPort = 51820
PrivateKey = <jouw_private_key_hier>

[Peer]
PublicKey = <public_key_van_client>
AllowedIPs = 10.0.0.2/32

# Start en enable Wireguard
systemctl enable --now wg-quick@wg0
