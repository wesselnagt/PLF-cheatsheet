🟢 Voorbeeldtoets E: RRAS NAT & Routing (GUI)

Doel: Zorg dat Core1 via RRAS1 kan communiceren met DC1 en het internet.

1. Netwerkkaarten inrichten (Server1/RRAS1)

  1. Voeg in VMware twee extra interfaces toe aan Server1 (Totaal = 3).
  2. Koppel Interface 1 aan LAN (bestaand), Interface 2 aan VMnet2 en Interface 3 aan NAT (VMnet8).
  3. Ga via ncpa.cpl naar de adapters:
    • Geef de VMnet2-adapter IP: 172.19.19.1 (Subnet: 255.255.255.0, geen gateway).
    • Zet de NAT-adapter op DHCP.

2. Core1 koppelen

  1. Zet de netwerkkaart van Core1 in VMware op VMnet2.
  2. In sconfig (optie 8): Geef IP 172.19.19.10, Subnet 255.255.255.0 en stel Gateway in op 172.19.19.1 (Server1).

3. RRAS Installeren & NAT configureren

  1. Open Server Manager op Server1 > Add Roles and Features.
  2. Kies Remote Access > Vink bij Role Services DirectAccess and VPN (RAS) én Routing aan. Behoud de standaard IIS-keuzes.
  3. Open Tools > Routing and Remote Access.
  4. Rechtsklik server > Configure and Enable... > Kies **Custom Configuration** > Vink **NAT** en **LAN Routing** aan. Start de service.
  5. Vouw IPv4 uit > Rechtsklik **NAT** > *New Interface* > Kies de interface die verbonden is met **VMnet8 (NAT)** > Vink aan: **Public interface connected to the Internet** + **Enable NAT on this interface**.

Aantonen: Ping vanaf Core1 naar 192.168.1.1 (DC1) en naar 8.8.8.8.

🟢 Voorbeeldtoets E: GPO "norun" & Wachtwoorden

1. GPO "norun" voor gebruiker Bob

  1. Open *Active Directory Users and Computers* (`dsa.msc`) en maak gebruiker bob aan.
  2. Open *Group Policy Management* (`gpmc.msc`).
  3. Rechtsklik op je domein/OU > *Create a GPO in this domain, and Link it here...* > Naam: norun.
  4. Rechtsklik de nieuwe GPO > *Edit*.
  5. Ga naar: *User Configuration* > *Policies* > *Administrative Templates* > *System*.
  6. Dubbelklik op **Don't run specified Windows applications** of ga naar *Start Menu and Taskbar* > **Remove Run menu from Start Menu** > Zet op **Enabled**.

2. Wachtwoord Policy (Fijnmazig of Default Domain Policy)

LET OP: Wachtwoordpolicies voor het hele domein *moeten* worden geconfigureerd in de Default Domain Policy óf via een Password Settings Object (PSO), anders werken ze niet op domeinniveau!
  1. In `gpmc.msc`: Rechtsklik op **Default Domain Policy** > *Edit*.
  2. Ga naar: *Computer Configuration* > *Policies* > *Windows Settings* > *Security Settings* > *Account Policies* > *Password Policy*.
  3. Pas de volgende waarden aan:
    • Maximum password age: 20 dagen.
    • Enforce password history: 3 wachtwoorden onthouden.
    • Minimum password length: 10 tekens.
  4. Zorg dat de policy geforceerd wordt (Rechtsklik op de GPO link > Vink **Enforced** aan).

🟣 Voorbeeldtoets F: Rocky Linux OpenVPN

Doel: Bouw een OpenVPN-tunnel tussen rocky1 (Server) en rocky2 (Client)[cite: 44, 65].

1. Netwerk & Repo Fix

  • Koppel rocky1 interface 1 aan het DC-netwerk (192.168.1.0/24, bijv IP 192.168.1.10). Voeg een tweede interface toe op **NAT (VMnet8)** via DHCP.
  • Zet rocky2 volledig op **NAT (VMnet8)** via DHCP.
  • Voer op beide systemen de **Repo Fix** uit (zie Toets Info).

2. OpenVPN Server (rocky1) configureren

sudo dnf install epel-release -y
sudo dnf install openvpn easy-rsa -y

# Easy-RSA initialiseren
make-cadir ~/openvpn-ca && cd ~/openvpn-ca
# Pas eventueel 'vars' aan indien vereist (zie toetsblad)
./easyrsa init-pki
./easyrsa build-ca nopass
./easyrsa gen-req server nopass
./easyrsa sign-req server server
./easyrsa gen-dh
openvpn --genkey secret ta.key

# Kopieer alles naar de openvpn map
sudo cp pki/ca.crt pki/issued/server.crt pki/private/server.key pki/dh.pem ta.key /etc/openvpn/server/

Maak een serverconfiguratie aan via `sudo nano /etc/openvpn/server/server.conf`:

port 1194
proto udp
dev tun
ca ca.crt
cert server.crt
key server.key
dh dh.pem
server 10.8.0.0 255.255.255.0
# Zorg dat de client het DC-netwerk kan vinden:
push "route 192.168.1.0 255.255.255.0"
keepalive 10 120
cipher AES-256-GCM
user nobody
group nobody
persist-key
persist-tun
status openvpn-status.log
verbosity 3
# Start de VPN server
sudo systemctl enable --now openvpn-server@server

3. Routing & IP Forwarding inschakelen op rocky1

Zonder dit commando kan de client nooit achter de server pingen!

sudo sysctl -w net.ipv4.ip_forward=1
# Maak permanent
echo "net.ipv4.ip_forward = 1" | sudo tee -a /etc/sysctl.conf

🟣 Voorbeeldtoets F: AD Sites & Replicatie (GUI)

Doel: Promoveer Core1 tot DC in school.test en richt replicatie in.

1. Sites & Subnets inrichten

  1. Open op DC1 *Active Directory Sites and Services* (`dssite.msc`).
  2. Rechtsklik *Sites* > *New Site* > Maak **Leeuwarden** en **Groningen** aan.
  3. Vouw *Subnets* uit > Rechtsklik > *New Subnet*:
    • Prefix: Netwerk van DC1 (bijv. 192.168.1.0/24) > Koppel aan **Leeuwarden**[cite: 45, 65].
    • Prefix: Netwerk van Core1 (bijv. 172.19.19.0/24) > Koppel aan **Groningen**[cite: 31, 65].
  4. Sleep `Dc1` vanuit zijn oude site handmatig naar de site **Leeuwarden**.

2. Replicatie Tijdschema aanpassen

  1. Vouw *Sites* > *Inter-Site Transports* > **IP** uit.
  2. Rechtsklik op de sitelink (bijv. *DEFAULTIPSITELINK*) > *Properties*.
  3. Zet *Replicate every* op 30 minuten (2x per uur).
  4. Klik op **Change Schedule**:
    • Selecteer het hele blok (Maandag t/m Vrijdag van 09:00 tot 18:00) > Zet op **Replication Available**.
    • Selecteer alle andere uren/dagen > Zet op **Replication Not Available**.

🟦 PowerShell: RRAS NAT Setup (Toets E)

Voer deze commando's uit op Server1/RRAS1 om binnen 10 seconden de routering en NAT werkend te krijgen:

# Installeren van de benodigde features
Install-WindowsFeature Remote-Access -IncludeManagementTools
Install-WindowsFeature Routing -IncludeManagementTools

# Configureer RRAS als LAN-router en NAT-gateway
Install-RemoteAccess -RoutingOnly

# Activeer NAT voor het interne netwerk segment
New-NetNat -Name "ToetsNAT" -InternalIPInterfaceAddressPrefix "172.19.19.0/24"

🟦 PowerShell: GPO & Wachtwoorden (Toets E)

Snel genereren van GPO's en het controleren van de wachtwoord policy.

# Maak de "norun" GPO aan
New-GPO -Name "norun" -Comment "Blokkeert run commando"
New-GPLink -Name "norun" -Target "DC=school,DC=test"

# Aantonen voor de leraar (Genereert het vereiste HTML rapport)
Get-GPO -Name "wachtwoord" | Get-GPOReport -ReportType HTML -Path "c:\report.html"

🟦 PowerShell: DC Promo & Replicatie (Toets F)

Gebruik dit op Core1 om hem te promoveren tot extra Domain Controller.

# 1. Activeer de Active Directory Domain Services role
Install-WindowsFeature AD-Domain-Services -IncludeManagementTools

# 2. Promoveer deze Core server tot extra DC in het bestaande domein
Install-ADDSDomainController -DomainName "school.test" -Credential (Get-Credential) -CriticalReplicationOnly:$false

# 3. NA REBOOT: Handmatige replicatie forceren en controleren (Aantonen!)
sync-ADObject -object "DC=school,DC=test" -source "Dc1"
repadmin /showrepl
