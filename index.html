⏱️ Start-routine & Tijdmanagement (45 min)

Je hebt 15 minuten per taak. Tijd is je grootste vijand.

  • Minuut 1-3: Lees de 3 taken. Identificeer afhankelijkheden. Moet je een CA opzetten voordat je VPN kunt configureren? Doe dat in de juiste volgorde.
  • Multitasken is verplicht: Start direct de installatie van zware Server Roles (ADDS, AD CS, RRAS). Terwijl de blauwe balkjes lopen, configureer je alvast IP-adressen of schrijf je je Linux configuratie uit.
  • Ping & DNS: 90% van de fouten komt door DNS. Werkt het joinen van een nieuwe VM aan het domein niet? Controleer direct je netwerkadapter: je Primary DNS moet naar je Domain Controller wijzen.

🟢 PLF08: Directory Services 1 (GUI)

Windows RRAS (Router & NAT) via GUI

  1. Role Installeren: Server Manager > Manage > Add Roles and Features > Vink Remote Access aan > Vink bij Role Services Routing aan.
  2. Activeren: Tools > Routing and Remote Access (RRAS).
  3. Rechtsklik op de servernaam > Configure and Enable Routing and Remote Access.
  4. Kies Custom Configuration > Vink NAT én LAN routing aan > Finish > Start de service.
  5. NAT Instellen: Vouw IPv4 uit > Rechtsklik op NAT > New Interface.
  6. Kies de netwerkkaart die naar buiten gaat (WAN) > Selecteer Public interface connected to the Internet > Vink Enable NAT on this interface aan. (Voeg daarna de interne interface toe als Private interface connected to private network).

VyOS Base Routing & NAT (Linux CLI)

configure
set interfaces ethernet eth0 address dhcp                # Buitenkant (WAN)
set interfaces ethernet eth1 address 192.168.10.1/24     # Binnenkant (LAN)

set nat source rule 100 outbound-interface eth0
set nat source rule 100 source address 192.168.10.0/24
set nat source rule 100 translation address masquerade

set protocols static route 0.0.0.0/0 next-hop <IP_VAN_GATEWAY>
commit
save
exit

🔵 PLF09: Directory Services 2 (GUI)

AD Sites & Subnets (GUI)

  1. Tools > Active Directory Sites and Services.
  2. Site aanmaken: Rechtsklik op Sites > New Site > Geef een naam en koppel aan DEFAULTIPSITELINK.
  3. Subnet koppelen: Rechtsklik op Subnets > New Subnet > Typ de prefix in (bijv. 10.0.0.0/24) > Selecteer in de lijst eronder de zojuist gemaakte Site.
  4. DC verplaatsen: Vouw de Default-First-Site-Name uit, sleep de Domain Controller naar de nieuwe Site.

DHCP Failover (GUI)

  1. Tools > DHCP > Vouw de lokale server uit > IPv4.
  2. Rechtsklik op een bestaande Scope > Configure Failover.
  3. Vink Select all aan > Next.
  4. Voer het IP of de naam in van je partner server (bijv. T-DHCP-02) > Next.
  5. Kies de Mode: Hot Standby of Load Balance.
  6. Vink State Switchover Interval aan (bijv. 1 minuut) > Next > Finish.

Storage Pools & Spaces (GUI)

  1. Server Manager > File and Storage Services > Volumes > Storage Pools.
  2. Rechtsklik rechtsboven in de lege ruimte (bij Primordial) > New Storage Pool.
  3. Rechtsklik op de nieuwe pool > New Virtual Disk (Kies Mirror of Parity).
  4. Doorloop de volume-wizard om een schijfletter en NTFS/ReFS in te stellen.

🟠 PLF10: Group Policies (GUI)

Central Store Aanmaken

  1. Kopieer de map: C:\Windows\PolicyDefinitions
  2. Plak deze in de SYSVOL share: \\JOUWDOMEIN.local\SYSVOL\JOUWDOMEIN.local\Policies\

Folder Redirection (GUI)

  1. Maak een map op je fileserver (deel deze met Everyone Full Control).
  2. Open gpmc.msc > Edit een GPO gelinkt aan de OU met Users.
  3. User Configuration > Policies > Windows Settings > Folder Redirection.
  4. Rechtsklik op Documents > Properties > Setting: Basic > Root Path: \\SERVERNAAM\Profiles.

Loopback Processing (Kiosk Mode)

  1. Link de GPO aan de OU waar de Computers in zitten.
  2. Edit GPO: Computer Configuration > Policies > Administrative Templates > System > Group Policy.
  3. Zet Configure user Group Policy loopback processing mode op Enabled > Kies Replace.

🔴 PLF11: Windows Beveiliging & PKI (GUI)

Enterprise CA (Certificate Authority)

  1. Installatie: Server Manager > Add Roles > Active Directory Certificate Services (Enterprise CA / Root CA).
  2. Template dupliceren: Tools > Certification Authority > Rechtsklik Certificate Templates > Manage.
  3. Duplicate een template, geef rechten bij Security voor de doelgroep: Read, **Enroll**, én **Autoenroll**.
  4. In de CA-console: Rechtsklik Certificate Templates > New > Certificate Template to Issue.

Auto-enrollment via GPO

  1. Edit GPO: User Configuration > Policies > Windows Settings > Security Settings > Public Key Policies.
  2. Open Certificate Services Client - Auto-Enrollment > Zet op Enabled en vink de vakjes aan.

🟣 PLF12: VPN & Beveiliging (GUI)

RRAS VPN (SSTP & L2TP)

  1. SSTP Certificaat: Vraag een Computer certificaat aan via certlm.msc.
  2. IIS Binding: Open IIS Manager > Default Web Site > Bindings > Voeg HTTPS toe op poort 443 en selecteer het certificaat.
  3. L2TP Preshared Key: In RRAS > Rechtsklik server > Properties > Tabblad Security > Vink Allow custom IPsec policy aan en typ de sleutel.

NPS (Network Policy Server) Instellen

  1. Tools > Network Policy Server > Policies > Network Policies > New.
  2. Conditions: Voeg de Active Directory Windows Group van je VPN-gebruikers toe.
  3. Constraints: Vink **MS-CHAP-v2** aan. Zorg dat de policy helemaal bovenaan staat.

🟦 PLF08: Routing & NAT via PowerShell

RRAS & NAT Configureren

Gebruik deze commando's op een Windows Server Core machine of om razendsnel te configureren zonder te hoeven klikken.

# 1. Installeer de Routing en Remote Access module
Install-WindowsFeature Remote-Access -IncludeManagementTools
Install-WindowsFeature Routing -IncludeManagementTools

# 2. Installeer Routing / NAT service (Vereist reboot van de service)
Install-RemoteAccess -RoutingOnly
Update-FileServerResourceManagementWallClock # Optioneel voor tijd-sync

# 3. NAT configureren op de externe interface (vervang "Ethernet0" door jouw WAN kaart naam)
New-NetNat -Name "ToetsNAT" -InternalIPInterfaceAddressPrefix "192.168.10.0/24"

🟦 PLF09: AD Sites & DHCP Failover via PowerShell

Active Directory Sites & Subnets

# Nieuwe site aanmaken
New-ADReplicationSite -Name "Groningen-Site"

# Subnet aanmaken en direct koppelen aan de Site
New-ADReplicationSubnet -Name "192.168.20.0/24" -Site "Groningen-Site"

# Server verplaatsen naar de nieuwe site
Move-ADDirectoryServer -Identity "T-DC-02" -TargetSite "Groningen-Site"

DHCP Failover configureren

Configureer een hot-standby of load-balance DHCP relatie tussen je main server en bijvoorbeeld T-DHCP-02.

# Failover relatie aanmaken (Hot Standby mode)
Add-DhcpServerv4Failover -Name "Main-to-Backup" -ScopeId 192.168.10.0 -PartnerServer "T-DHCP-02.jouwdomein.local" -ServerRole Standby -ReservePercent 5 -MaxClientLeadTime 00:10:00 -AutoStateTransition $true -StateSwitchoverInterval 00:01:00 -SharedSecret "MijnGeheimWachtwoord123!"

🟦 PLF10: Group Policies via PowerShell

GPO Aanmaken en Linken

# Nieuwe GPO aanmaken
New-GPO -Name "Kiosk_Restrictions" -Comment "Beveiliging voor openbare PC's"

# GPO linken aan een specifieke OU
New-GPLink -Name "Kiosk_Restrictions" -Target "OU=Kiosks,OU=Bedrijf,DC=jouwdomein,DC=local"

# GPO Link op "Enforced" zetten
Set-GPLink -Name "Kiosk_Restrictions" -Target "OU=Kiosks,OU=Bedrijf,DC=jouwdomein,DC=local" -Enforced Yes

🟦 PLF11: Firewall & IPsec via PowerShell

IPsec Isolatieregel aanmaken

Verplicht Kerberos v5 authenticatie voor alle inkomende en uitgaande verbindingen.

# Maak een nieuwe IPsec / Connection Security Rule aan
New-NetInboundDiagTrackConnectionSecurityRule -DisplayName "Domain Isolation Rule" -Endpoint1 Any -Endpoint2 Any -AuthenticationMethod ComputerKerberos -InboundSecurity Require -OutboundSecurity Request

🟦 PLF12: VPN & NPS via PowerShell

L2TP Pre-Shared Key instellen op de RRAS gateway

# Stel de IPsec Pre-Shared Key in voor L2TP VPN verbindingen
Set-VpnAuthProtocol -TunnelAuthProtocols L2TP -SharedSecret "Welkom01!" -UserAuthProtocolsEap MSCHAPv2

NPS Network Policy exporteren en importeren

Als je je NPS instellingen snel wilt backuppen of verplaatsen naar een andere server:

# Exporteer de volledige NPS configuratie naar een XML bestand
Export-NpsConfiguration -Path "C:\NpsConfig.xml"

# Importeer de configuratie op de nieuwe server
Import-NpsConfiguration -Path "C:\NpsConfig.xml"
