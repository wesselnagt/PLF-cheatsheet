🔴 TOETS E: Volledige Overlevingsgids

Focus: Routing (NAT) opzetten en Group Policies beveiligen.

Zorg dat al je 3 virtuele machines aan staan: DC1, je GUI-server (wordt RRAS1) en je Core-server (wordt Core1).

Deel 1: Netwerkkaarten in VMware instellen

  1. Klik in VMware bovenin op de tab van je GUI-server (RRAS1).
  2. Klik op VM > Settings.
  3. Zorg dat je in totaal DRIE (3) Network Adapters hebt. Klik eventueel op Add... > Network Adapter > Finish als je er tekort komt.
  4. Stel ze exact zo in:
    - Network Adapter 1: Selecteer Custom: VMnet0 (Dit is de koppeling naar DC1).
    - Network Adapter 2: Selecteer Custom: VMnet2 (Dit is de koppeling naar Core1).
    - Network Adapter 3: Selecteer Custom: VMnet8 (NAT) (Dit is het internet).
  5. Klik op OK.
  6. Ga in VMware naar de tab van je Core-server (Core1). Klik op VM > Settings.
  7. Zorg dat deze ÉÉN (1) Network Adapter heeft. Stel deze in op Custom: VMnet2. Klik op OK.

Deel 2: IP-adressen uitdelen en Ping aanzetten

SERVER: CORE1
  1. Log in op Core1. Het zwarte CMD-scherm opent.
  2. Typ sconfig en druk op Enter.
  3. Typ 2 (Computer Name) en druk op Enter. Typ die naam Core1 en druk op Enter. Hij vraagt om een herstart, klik Yes.
  4. Na herstart log je weer in en typ je weer sconfig.
  5. Typ 4 (Configure Remote Management) > Typ 3 (Configure Server Response to Ping) > Klik Yes in de pop-up. (Ping is nu aan).
  6. Typ 4 (Return to main menu).
  7. Typ 8 (Network Settings) en druk op Enter.
  8. Kies het getal van je netwerkkaart (meestal 1) en druk op Enter.
  9. Typ 1 (Set Network Adapter Address) > Typ S (Static) > Typ als IP 172.19.19.2 > Typ als Subnetmasker 255.255.255.0 > Typ als Default Gateway 172.19.19.1.
  10. Typ 2 (Set DNS Servers) > Typ 192.168.1.1 > Druk op Enter. Typ daarna 4 om terug te gaan.
SERVER: RRAS1 (GUI)
  1. Log in op RRAS1. Druk op de Windows-toets, typ PowerShell en druk op Enter.
  2. Kopieer, plak en voer deze commando's één voor één uit:
    3. # Interface naar Core1 instellen:
New-NetIPAddress -InterfaceAlias "Ethernet 1" -IPAddress 172.19.19.1 -PrefixLength 24

# Interface naar de Domain Controller (DC1) instellen:
New-NetIPAddress -InterfaceAlias "Ethernet 0" -IPAddress 192.168.1.10 -PrefixLength 24

Deel 3: Router & NAT Installeren op RRAS1

SERVER: RRAS1 (GUI)
  1. Open Server Manager. Klik rechtsboven op Manage > Add Roles and Features.
  2. Klik 3x op Next tot je bij 'Server Roles' bent.
  3. Vink Remote Access aan. Klik 3x op Next tot je bij 'Role Services' bent.
  4. Vink DirectAccess and VPN (RAS) aan (Klik 'Add Features' in de pop-up). Vink ook Routing aan.
  5. Klik op Next en daarna op Install. Wacht tot hij klaar is en klik Close.
  6. Druk op de Windows-toets, typ rrasmgmt.msc en druk op Enter.
  7. Klik met de rechtermuisknop op de naam van je server og klik op Configure and Enable Routing and Remote Access.
  8. Klik Next, selecteer Network address translation (NAT) en klik Next.
  9. Selecteer de netwerkkaart die met VMnet8 (het internet) is verbonden. Klik Next en dan Finish.
  10. Gateway-conflict fixen: Open PowerShell op RRAS1 en voer dit uit om te zorgen dat het internet altijd voorrang krijgt:
    11. Set-NetIPInterface -InterfaceAlias "VMnet8" -InterfaceMetric 5
Set-NetIPInterface -InterfaceAlias "Ethernet 0" -InterfaceMetric 80
Set-NetIPInterface -InterfaceAlias "Ethernet 1" -InterfaceMetric 80
TESTMOMENT (PLF08 KLAAR): Ga naar Core1. Typ ping 8.8.8.8. Werkt dit? Gefeliciteerd!

Deel 4: Group Policies (GPO) configureren op DC1

SERVER: DC1
  1. Druk op de Windows-toets, typ dsa.msc (Active Directory Users and Computers) en druk op Enter.
  2. Klik rechtermuisknop op je domeinnaam (bijv. school.test) > New > Organizational Unit. Typ ToetsOU en klik OK.
  3. Klik rechtermuisknop op de map ToetsOU > New > User. Typ als naam bob. Klik Next, typ als wachtwoord Pa$$w0rd en rond af.
  4. Druk op de Windows-toets, typ gpmc.msc (Group Policy Management) en druk op Enter.
  5. Vouw de mapjes open: Forest > Domains > school.test.
  6. Klik rechtermuisknop op de map Group Policy Objects > New. Typ wachtwoord en klik OK.
  7. Klik rechtermuisknop op wachtwoord en kies Edit.
  8. Navigeer naar: Computer Configuration > Policies > Windows Settings > Security Settings > Account Policies > Password Policy.
  9. Dubbelklik op Enforce password history > Zet vinkje bij 'Define' > vul in 3 > OK.
  10. Dubbelklik op Maximum password age > vul in 20 > OK.
  11. Dubbelklik op Minimum password length > vul in 10 > OK. Sluit de Editor af.
  12. LET OP: Klik rechtermuisknop helemaal bovenaan op je domeinnaam (school.test) en kies Link an Existing GPO.... Selecteer wachtwoord en klik OK.
  13. Klik rechtermuisknop op de verschenen koppeling en klik op Enforced.
  14. Maak weer een New GPO in Group Policy Objects genaamd norun. Rechtermuisknop > Edit.
  15. Navigeer naar: User Configuration > Policies > Administrative Templates > System.
  16. Dubbelklik op Prevent access to the command prompt > Klik Enabled aan > Klik OK. Sluit de Editor.
  17. Klik rechtermuisknop op de map ToetsOU (waar Bob in zit) > Link an Existing GPO... > Kies norun > OK.
  18. Klik rechtermuisknop op deze nieuwe koppeling en klik op Enforced.

Deel 5: Rapport genereren voor de docent

SERVER: DC1
  1. Open PowerShell op DC1.
  2. Voer dit commando uit om je HTML bewijs te maken:
    3. Get-GPO -Name "wachtwoord" | Get-GPOReport -ReportType HTML -Path C:\report.html
  3. Log op een werkplek in als bob en laat de docent zien dat CMD blokkeert!

🔴 TOETS F: Volledige Overlevingsgids

Focus: Linux OpenVPN Server-Client en Windows AD Sites Maken.

Deel 1: VMware & Linux Repositories Fixen

  1. Zorg dat je DC1 aan staat. Start rocky1 op. Laad rocky2 in via File > Open in VMware en start deze ook.
  2. Koppel in VMware de netwerkkaarten:
    - rocky1: Adapter 1 = Custom: VMnet0 (naar DC1). Voeg een 2e Adapter toe via Settings > Add en zet deze op Custom: VMnet8 (NAT).
    - rocky2: Heeft maar 1 adapter nodig. Zet deze op Custom: VMnet8 (NAT).
  3. Log in op BEIDE Linux machines als root en voer op allebei dit uit om de repo's en software te fixen:
    4. sudo rm -f /etc/yum.repos.d/Rocky-*
sudo dnf reinstall rocky-repos -y
sudo dnf install epel-release -y
sudo dnf install openvpn easy-rsa -y

Deel 2: OpenVPN Server bouwen op Rocky1

SERVER: ROCKY1
  1. Voer deze commando's achter elkaar uit om de CA op te zetten:
    2. mkdir ~/openvpn-ca
cd ~/openvpn-ca
easyrsa init-pki
  2. Typ nano vars. Haal de # weg en vul onderaan in: NL, Utrecht, Utrecht, Institute for ICT, admin@ict.test. Druk op Ctrl+O > Enter > Ctrl+X.
  3. Bouw de certificaten zonder de `./` prefix:
    4. easyrsa build-ca nopass
easyrsa gen-req server nopass
easyrsa sign-req server server
easyrsa gen-dh
openvpn --genkey secret ta.key
easyrsa gen-req client1 nopass
easyrsa sign-req client client1
  4. Verplaats de bestanden naar de server map:
    5. sudo cp pki/ca.crt pki/issued/server.crt pki/private/server.key dh.pem ta.key /etc/openvpn/server/
  5. Maak de configuratie aan: sudo nano /etc/openvpn/server/server.conf
  6. Plak dit bestand erin (Let op: onderaan staat verb 3, géén verbosity!):
    7. port 1194
proto udp
dev tun
ca ca.crt
cert server.crt
key server.key
dh dh.pem
server 10.8.0.0 255.255.255.0
push "route 192.168.1.0 255.255.255.0"
keepalive 10 120
tls-auth ta.key 0
cipher AES-256-GCM
user nobody
group nobody
persist-key
persist-tun
status openvpn-status.log
verb 3
  7. Sla op (Ctrl+O > Enter > Ctrl+X).
  8. BELANGRIJK: Open de Firewall en zet Routering aan op Rocky1! Voer deze commando's uit:
    9. sudo firewall-cmd --zone=public --add-port=1194/udp --permanent
sudo firewall-cmd --zone=external --add-port=1194/udp --permanent
sudo firewall-cmd --zone=trusted --add-port=1194/udp --permanent
sudo firewall-cmd --zone=public --add-masquerade --permanent
sudo firewall-cmd --zone=external --add-masquerade --permanent
sudo firewall-cmd --reload
sudo sysctl -w net.ipv4.ip_forward=1
  9. Start nu de serverdienst op Rocky1: sudo systemctl enable --now openvpn-server@server

Deel 3: Client Koppelen (rocky2)

SERVER: ROCKY2
  1. Zorg eerst dat de mappenstructuur bestaat: sudo mkdir -p /etc/openvpn/client/
  2. Trek de sleutels veilig over vanaf Rocky1 via SCP (vervang [NAT-IP-ROCKY1] door het IP van ens224): 
    sudo scp wnagtegaal@[NAT-IP-ROCKY1]:/home/wnagtegaal/openvpn-ca/pki/ca.crt wnagtegaal@[NAT-IP-ROCKY1]:/home/wnagtegaal/openvpn-ca/pki/issued/client1.crt wnagtegaal@[NAT-IP-ROCKY1]:/home/wnagtegaal/openvpn-ca/pki/private/client1.key wnagtegaal@[NAT-IP-ROCKY1]:/home/wnagtegaal/openvpn-ca/ta.key /etc/openvpn/client/
  3. Typ: sudo nano /etc/openvpn/client/client.conf op rocky2.
  4. Plak deze configuratie erin en vul het juiste IP in bij remote:
    5. client
dev tun
proto udp
remote [NAT-IP-VAN-ROCKY1] 1194
resolv-retry infinite
nobind
user nobody
group nobody
persist-key
persist-tun
ca ca.crt
cert client1.crt
key client1.key
remote-cert-tls server
tls-auth ta.key 1
cipher AES-256-GCM
verb 3
  5. Sla op met Ctrl+O > Enter > Ctrl+X.
  6. Start de clientverbinding op rocky2: 
    sudo systemctl enable --now openvpn-client@client
  7. Test vanaf rocky2 met: ping -c 3 192.168.1.1. Krijg je antwoord? Dan werkt de VPN perfect!

Deel 4: Active Directory Sites opzetten & Replicatie

SERVER: DC1 (GUI)
  1. Zorg dat Core1 gepromoveerd is tot Domain Controller (zie PLF09 als je dit nog niet hebt gedaan).
  2. Druk op de Windows-toets, typ dssite.msc en druk op Enter.
  3. Klik rechtermuisknop op de map Sites > New Site...
  4. Typ Leeuwarden, klik op DEFAULTIPSITELINK en klik OK. Doe hetzelfde voor Groningen.
  5. Klik rechtermuisknop op de map Subnets > New Subnet...
  6. Typ 192.168.1.0/24, klik op Leeuwarden en OK.
  7. Typ 172.19.19.0/24, klik op Groningen en OK.
  8. Vouw open: Sites > Default-First-Site-Name > Servers.
  9. Sleep DC1 naar de map Leeuwarden. Sleep Core1 naar de map Groningen.
  10. Vouw open: Inter-Site Transports > IP.
  11. Klik rechtermuisknop op DEFAULTIPSITELINK aan de rechterkant en kies Properties.
  12. Verander Replicate every naar 30 minuten.
  13. Klik op Change Schedule...
  14. Zet alles op wit (klik Replication Not Available en selecteer alles).
  15. Selecteer het blok Maandag t/m Vrijdag, 09:00 tot 18:00 en klik op Replication Available (wordt blauw). Klik OK.
  16. Open Command Prompt en forceer replicatie:
    17. repadmin /syncall /AePdq
Toets F is afgerond! Laat je Command Prompt en Linux Pings openstaan.

PLF08: Directory Services Deel 1 (Routing & NAT)

Verander een Windows Server in een softwarematige router (RRAS).

1. IP-configuraties vastleggen

SERVER: RRAS1 (GUI)
  1. Druk op de Windows-toets, typ PowerShell en druk op Enter.
  2. Stel de interne netwerkkaart (naar DC1) in: 
    New-NetIPAddress -InterfaceAlias "Ethernet 0" -IPAddress 192.168.1.10 -PrefixLength 24
  3. Stel de tweede netwerkkaart (naar Core1) in: 
    New-NetIPAddress -InterfaceAlias "Ethernet 1" -IPAddress 172.19.19.1 -PrefixLength 24

2. Remote Access Rol Installeren

SERVER: RRAS1 (GUI)
  1. Open Server Manager. Klik op Manage > Add Roles and Features.
  2. Klik 3x op Next tot 'Server Roles'.
  3. Vink Remote Access aan. Klik 3x op Next.
  4. Vink bij 'Role Services' DirectAccess and VPN (RAS) aan (Accepteer de pop-up).
  5. Vink ook Routing aan.
  6. Klik op Next > Install. Wacht tot dit klaar is en klik op Close.

3. NAT Inschakelen via de RRAS Console

SERVER: RRAS1 (GUI)
  1. Druk op de Windows-toets, typ rrasmgmt.msc en druk op Enter.
  2. Klik met de rechtermuisknop op de naam van je server en kies Configure and Enable Routing and Remote Access.
  3. Klik op Next, kies Network address translation (NAT) en klik op Next.
  4. Selecteer in de lijst de netwerkkaart die verbonden is met het internet (vaak een IP uit de 192.168.91.x reeks via DHCP) en klik Next.
  5. Klik op Finish.
  6. Zorg dat internet voorrang krijgt via PowerShell: 
    Set-NetIPInterface -InterfaceAlias "VMnet8" -InterfaceMetric 5

PLF09: Directory Services Deel 2 (Sites)

Verdeel je Active Directory over meerdere fysieke locaties en beheer de replicatie.

1. Core Server promoveren tot Domain Controller

SERVER: CORE1
  1. Log in op Core1. Typ powershell in het zwarte CMD-scherm.
  2. Installeer de benodigde server rollen: 
    Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools
  3. Voeg de server toe aan het bestaande domein als Domain Controller: 
    Install-ADDSDomainController -DomainName "school.test" -Credential (Get-Credential)
  4. Er popt een inlogschermpje op: typ school\Administrator met je wachtwoord. Druk op Enter en laat de server herstarten.

2. Sites en Subnets Maken

SERVER: DC1 (GUI)
  1. Druk op de Windows-toets, typ dssite.msc en druk op Enter.
  2. Klik rechtermuisknop op de map Sites > New Site...
  3. Typ Leeuwarden, klik op DEFAULTIPSITELINK en klik op OK. Doe dit nogmaals voor site Groningen.
  4. Klik rechtermuisknop op de map Subnets > New Subnet...
  5. Typ 192.168.1.0/24, selecteer Leeuwarden in de lijst en klik op OK.
  6. Klik nogmaals rechtermuisknop > New Subnet..., typ 172.19.19.0/24, selecteer Groningen en klik op OK.
  7. Vouw open: Sites > Default-First-Site-Name > Servers.
  8. Klik op DC1, houd de muis ingedrukt en sleep deze naar de site Leeuwarden.
  9. Sleep vervolgens Core1 naar de site Groningen.

3. Sitelink configureren

SERVER: DC1 (GUI)
  1. Vouw aan de linkerkant open: Inter-Site Transports > IP.
  2. Klik rechtermuisknop op DEFAULTIPSITELINK aan de rechterkant > kies Properties.
  3. Verander Replicate every naar 30 minutes.
  4. Klik op Change Schedule...
  5. Zet alles op wit (klik op Replication Not Available en selecteer het hele rooster).
  6. Selecteer met je muis het blok Maandag t/m Vrijdag van 09:00 tot 18:00, klik op Replication Available (wordt blauw) en klik OK.

PLF10: Group Policies (GPO)

Windows groepsbeleid maken en forceren in de Active Directory.

1. De Wachtwoord Policy (Domein Niveau)

SERVER: DC1 (GUI)
  1. Druk op de Windows-toets, typ gpmc.msc en druk op Enter.
  2. Vouw Forest > Domains > school.test open.
  3. Klik rechtermuisknop op de map Group Policy Objects > New. Typ wachtwoord_policy en klik OK.
  4. Klik rechtermuisknop op de nieuwe wachtwoord_policy > Edit.
  5. Klik door naar: Computer Configuration > Policies > Windows Settings > Security Settings > Account Policies > Password Policy.
  6. Dubbelklik op Enforce password history > Zet vinkje bij 'Define' > vul in 3 > OK.
  7. Dubbelklik op Maximum password age > vul in 20 > OK.
  8. Dubbelklik op Minimum password length > vul in 10 > OK. Sluit deze Editor af.
  9. Klik nu links rechtermuisknop helemaal bovenaan op je domeinnaam school.test > Link an Existing GPO... > Selecteer wachtwoord_policy > OK.
  10. Klik rechtermuisknop op de verschenen koppeling en klik Enforced.

2. De Restrictie Policy (OU Niveau)

SERVER: DC1 (GUI)
  1. Maak weer een nieuwe GPO in Group Policy Objects. Noem deze cmd_block.
  2. Klik rechtermuisknop > Edit.
  3. Klik door naar: User Configuration > Policies > Administrative Templates > System.
  4. Dubbelklik op Prevent access to the command prompt > Selecteer Enabled bovenaan > klik OK. Sluit de Editor.
  5. Zoek aan de linkerkant de map van je Gebruikers OU op (bijv. de map met je leerlingen of werknemers).
  6. Klik rechtermuisknop op die OU > Link an Existing GPO... > Selecteer cmd_block > OK.
  7. Klik rechtermuisknop op de koppeling en vink Enforced aan.

PLF11: Windows Systeembeveiliging & PKI

Installeer een Enterprise Certificaat Autoriteit en configureer Audit Logging.

1. Active Directory Certificate Services (AD-CS) Installeren

SERVER: DC1 (GUI)
  1. Open Server Manager. Klik op Manage > Add Roles and Features.
  2. Klik Next tot aan 'Server Roles'. Vink Active Directory Certificate Services aan (Add features).
  3. Klik Next tot de installatie start. Klik op Install en wacht tot hij klaar is.
  4. Bovenin Server Manager staat nu een geel uitroepteken-vlaggetje. Klik hierop en selecteer Configure Active Directory Certificate Services...
  5. Zorg dat je bent ingelogd als SCHOOL\Administrator en klik Next.
  6. Vink Certification Authority aan en klik Next.
  7. Selecteer Enterprise CA (zodat AD-computers het certificaat automatisch krijgen) en klik Next.
  8. Selecteer Root CA en klik Next.
  9. Selecteer Create a new private key en klik Next.
  10. Laat de hash op SHA256 staan en klik Next totdat je op Configure kunt klikken.

2. Inlogpogingen Loggen (Audit Policy)

SERVER: DC1 (GUI)
  1. Druk op de Windows-toets, typ gpmc.msc en druk op Enter.
  2. Klik rechtermuisknop op Default Domain Policy > kies Edit.
  3. Navigeer exact naar: Computer Configuration > Policies > Windows Settings > Security Settings > Local Policies > Audit Policy.
  4. Aan de rechterkant zie je nu verschillende policies. Dubbelklik op Audit logon events.
  5. Zet een vinkje bij Define these policy settings.
  6. Vink zowel Success als Failure aan en klik OK.
  7. Sluit de vensters. Vanaf nu kun je in de Windows Event Viewer (eventvwr.msc) onder Security precies zien wie is ingelogd of wie een verkeerd wachtwoord heeft getypt!
